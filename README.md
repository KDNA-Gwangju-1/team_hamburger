# team\_hamburger



저장: 현 상황의 정보를 지정한 위치에 넣는것
커밋: 특정 구간에서 현 상황의 정보를 또 다른 위치에 넣는것

이채호 : 저장과 커밋이 다른 점은 저장은 한번 하면 과거의 형상 혹은 형태로 돌아가기 어렵지만, 커밋은 기록이 남아서 해당 시점으로 돌아갈 수 있다. 이러한 기능 덕분에 오류나 에러가 나기 전 시점으로 돌아가거나, 시험적인 기능을 테스트할 수 있다.

최규용- 저장은 최종적으로 서버에 올리는 느낌이고 커밋은 서버에 올리기 전 최종 점검 느낌(저장하기 전에 마지막 확인)이다.

김석주
저장: 현 상황의 정보를 지정한 위치에 넣는것
커밋: 특정 구간에서 현 상황의 정보를 또 다른 위치에 넣는것

이도현 - 저장과 커밋을 둘다 파일을 온전한 상태로 보존해서 클라우드에 올린다는 것이 똑같지만 저장은 실시간으로 수정하기가 상당히 힘든 반면 커밋은 실시간으로 수정이 가능하다
